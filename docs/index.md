# DualEntry Skills documentation

DualEntry skills are portable instruction sets for AI agents. Each one is a `SKILL.md` file that
describes a task in DualEntry: when to use it, the defaults to apply, and the steps to follow.

## Start here

1. [Install](installation.md) the skills with the Skills CLI.
2. [Connect](authentication.md) your agent to DualEntry. Skills contain instructions only, so an
   agent needs a DualEntry connection to read any data.
3. Ask your agent a question the skill covers, such as "Which bills are due in the next 10 days?"

## Surface compatibility

All current skills use the MCP surface and are read-only.

| Surface | Supported |
|---|---|
| MCP | Yes |
| CLI | Not yet |
